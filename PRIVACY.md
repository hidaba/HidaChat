# Privacy Policy for HidaChat

**Last Updated:** October 9, 2026  
**Repository:** [https://github.com/hidaba/HidaChat](https://github.com/hidaba/HidaChat)

This Privacy Policy explains how **HidaChat** handles personal data, login sessions, messages, and network interactions. HidaChat is an open-source, portable Windows desktop client (.NET 9 / WPF) that runs multi-account instances of web-based messaging platforms and AI gateway services via Microsoft Edge WebView2.

HidaChat is designed from the ground up with a **local-first, 100% portable privacy model**. The application does not include any telemetry, analytics, tracking frameworks, remote user databases, or developer-hosted backend servers. The developer of HidaChat does not collect, receive, store, or sell any personal information.

---

## 1. What Data HidaChat Accesses and Retains

When you use HidaChat to access messaging services (such as WhatsApp Web and Telegram Web), the application hosts each service inside an isolated Microsoft Edge WebView2 environment.

HidaChat accesses and stores the following data locally on your machine:

- **Authentication Sessions & Cookies:** Cookies and session tokens generated by web services (e.g., `web.whatsapp.com`, `web.telegram.org`) to keep you logged in between application restarts.
- **Local Storage & IndexedDB / LevelDB:** Web application databases used natively by WhatsApp Web and Telegram Web to store local encryption keys, offline state, and cached conversations.
- **Browser Cache:** Cached images, scripts, stylesheets, and media files downloaded to accelerate page loading.
- **Notifications & Message Previews:** Incoming message snippets and sender names received via the web services are captured locally in memory to display Windows native toast notifications and desktop overlay popups. Message text is not logged or written to disk outside of the standard browser cache.
- **Application Configuration:** User settings, such as configured account names, platform types, interface language, and notification preferences, stored in `data/settings.json`.

## 2. Where Profile Data is Stored, Retention, and Deletion

### Local Storage Location
HidaChat is strictly portable. **All** data, including WebView2 user profiles, cookies, cache, and configuration, is stored exclusively inside the application folder:

```
<HidaChat_Directory>/data/
  ├── settings.json
  └── webview/
      └── WV2Profile_<accountId>/
          └── EBWebView/
```

HidaChat never creates files or writes personal profile data to external system locations such as `%LOCALAPPDATA%`, `%APPDATA%`, or `%TEMP%`.

### Data Retention
- Profile data remains stored in the `data/webview/` directory until you log out from the service, delete the account in HidaChat, or manually delete the files.
- HidaChat does not automatically expire or purge active login tokens unless instructed by the underlying web service.

### How Users Can Delete Their Data
You have complete control over your data:
1. **Removing an Account in HidaChat:** Open Settings > Accounts, select an account, and choose "Delete". This removes the account registration from HidaChat.
2. **Complete Data Removal:** Close HidaChat and delete the `data` directory located in the application folder. This permanently erases all saved login sessions, cookies, cached messages, and preferences.

### Security Implications of Portable and Removable Storage
Because HidaChat stores authentication tokens and session cookies directly inside its directory to achieve 100% portability:
- If you run HidaChat from a **USB flash drive, external hard drive, or shared network drive**, anyone with physical or network read access to that drive could potentially copy the profile folders and access your active messaging sessions.
- **Recommendation:** Always use disk encryption (such as Windows BitLocker To Go) on removable drives containing HidaChat, and ensure shared folders have strict file permissions.

## 3. Message Translation Feature and External Transmission

HidaChat includes an optional built-in message translation feature that allows you to translate incoming or outgoing messages and entire chat threads.

- **Transmission to Google Translate:** When you initiate a translation (by hovering over a message, clicking the translate icon, or using thread translation), the plain text content of that specific message is transmitted directly over HTTPS to Google Translate (`https://translate.googleapis.com/`).
- **Purpose:** The transmission is performed exclusively to fetch the translated text and display it in the interface.
- **No Identifiers or Credentials:** HidaChat does not attach your account credentials, cookies, phone numbers, contact lists, or personal identifiers to translation requests.
- **User Control:** Translation is strictly on-demand. Text is only sent when you interact with the translation controls. You can also disable translation tooltips and features in the application settings.

## 4. Third-Party Services and Their Roles

HidaChat interacts with the following external services:

1. **WhatsApp Web (Meta Platforms, Inc.):**
   - **Role:** Web messaging platform loaded inside WebView2 (`web.whatsapp.com`).
   - **Privacy Policy:** [https://www.whatsapp.com/legal/privacy-policy](https://www.whatsapp.com/legal/privacy-policy)
2. **Telegram Web (Telegram FZ-LLC):**
   - **Role:** Web messaging platform loaded inside WebView2 (`web.telegram.org`).
   - **Privacy Policy:** [https://telegram.org/privacy](https://telegram.org/privacy)
3. **Google Translate (Google LLC):**
   - **Role:** Third-party translation API provider (`translate.googleapis.com`).
   - **Privacy Policy:** [https://policies.google.com/privacy](https://policies.google.com/privacy)
4. **GitHub Releases (GitHub, Inc. / Microsoft Corp.):**
   - **Role:** Anonymous release checks via `https://api.github.com/repos/hidaba/HidaChat/releases/latest` to notify you of available software updates. No user data is transmitted.
5. **Tailscale (Tailscale Inc.) — Optional:**
   - **Role:** Optional peer-to-peer mesh VPN companion (`tsnetd`) used only if you explicitly configure connections to self-hosted OpenClaw or Hermes Agent gateways across a Tailscale tailnet.
   - **Privacy Policy:** [https://tailscale.com/privacy-policy](https://tailscale.com/privacy-policy)

## 5. User Controls and Choices

HidaChat provides direct settings for all data-related features:

- **Notifications:** Enable or disable toast notifications and overlay popups globally or per account.
- **Message Translation:** Enable, disable, or adjust target translation languages in Settings.
- **Account Profiles:** Add, edit, or delete accounts at any time.
- **Proxy & Network:** Configure custom proxy servers or Tailscale settings per account.
- **Offline / Isolated Mode:** You can use HidaChat entirely without translation or companion network daemons.
